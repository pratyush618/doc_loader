OCR (Optical Character Recognition) enables the Document Converter to extract text from images, scanned documents, and PDFs that contain non-selectable text.

The Document Converter supports multiple OCR providers, each with different strengths:

## OCR Quality Factors

<AccordionGroup>
  <Accordion title="Image Quality">
    **Resolution:**
    - Minimum: 150 DPI
    - Recommended: 300+ DPI
    - Higher resolution = better accuracy
    
    **Contrast:**
    - High contrast between text and background
    - Black text on white background is ideal
    - Avoid low contrast color combinations
    
    **Clarity:**
    - Sharp, focused images
    - Avoid blurry or pixelated text
    - Good lighting conditions
  </Accordion>
  
  <Accordion title="Text Characteristics">
    **Font Size:**
    - Minimum: 10pt font size
    - Recommended: 12pt or larger
    - Very small text may be missed
    
    **Font Type:**
    - Sans-serif fonts work better
    - Avoid decorative or script fonts
    - Standard fonts (Arial, Times) are ideal
    
    **Text Orientation:**
    - Horizontal text works best
    - Vertical text supported but less accurate
    - Avoid skewed or rotated text
  </Accordion>
  
  <Accordion title="Layout Considerations">
    **Structure:**
    - Clear column separation
    - Consistent spacing
    - Avoid overlapping text
    
    **Background:**
    - Clean, uniform background
    - Avoid patterns or textures
    - Remove noise and artifacts
    
    **Margins:**
    - Adequate white space around text
    - Clear boundaries between sections
    - Avoid text near edges
  </Accordion>
</AccordionGroup>

```python PaddleOCR Advanced
from paddleocr import PaddleOCR

# Initialize with custom settings
ocr = PaddleOCR(
    use_angle_cls=True,  # Detect text angle
    lang='en',           # Language
    use_gpu=False,       # GPU acceleration
    show_log=False,      # Disable logging
    
    # Detection parameters
    det_db_thresh=0.3,
    det_db_box_thresh=0.5,
    det_db_unclip_ratio=1.6,
    
    # Recognition parameters
    rec_batch_num=6,
    max_text_length=25,
    
    # Text direction classification
    cls_batch_num=6,
    cls_thresh=0.9,
)
```

import easyocr

# Initialize with custom settings
reader = easyocr.Reader(

## Troubleshooting

<AccordionGroup>
  <Accordion title="PaddleOCR Issues">
    **Common Problems:**
    - Model download failures
    - CUDA compatibility issues
    - Memory errors with large images
    
    **Solutions:**
    ```bash
    # Pre-download models
    python -c "from paddleocr import PaddleOCR; PaddleOCR(use_angle_cls=True, lang='en')"
    
    # Disable GPU if issues
    PADDLE_OCR_USE_GPU=false
    
    # Increase memory limits
    export MALLOC_ARENA_MAX=4
    ```
  </Accordion>
  
  <Accordion title="EasyOCR Issues">
    **Common Problems:**
    - PyTorch installation issues
    - CUDA version mismatches
    - Model loading failures
    
    **Solutions:**
    ```bash
    # Reinstall PyTorch
    pip uninstall torch torchvision torchaudio
    pip install torch torchvision torchaudio --index-url https://download.pytorch.org/whl/cpu
    
    # Clear model cache
    rm -rf ~/.EasyOCR/
    
    # Use CPU only
    EASY_OCR_USE_GPU=false
    ```
  </Accordion>
  
  <Accordion title="Mistral AI Issues">
    **Common Problems:**
    - API key authentication failures
    - Rate limiting errors
    - Network connectivity issues
    
    **Solutions:**
    ```bash
    # Test API key
    curl -H "Authorization: Bearer $MISTRAL_API_KEY" \
         "https://api.mistral.ai/v1/models"
    
    # Check rate limits
    # Implement exponential backoff
    # Monitor API usage
    ```
  </Accordion>
  
  <Accordion title="General OCR Issues">
    **Poor Accuracy:**
    - Improve image quality
    - Use correct language settings
    - Try different OCR providers
    - Preprocess images (noise reduction, contrast enhancement)
    
    **Slow Processing:**
    - Use GPU acceleration
    - Reduce image resolution
    - Process in batches
    - Consider hardware upgrades
    
    **Memory Issues:**
    - Reduce image size
    - Process images sequentially
    - Increase system memory
    - Use image compression
  </Accordion>
</AccordionGroup>

```bash Batch OCR Processing
#!/bin/bash

# Process multiple images with OCR
for file in *.png *.jpg; do
    echo "Processing $file..."
    
    RESPONSE=$(curl -s -X POST "http://localhost:8000/api/v1/jobs" \
        -F "file=@$file" \
        -F "output_format=md" \
        -F "use_ocr=true" \
        -F "ocr_provider=paddle")
    
    JOB_ID=$(echo $RESPONSE | jq -r '.id')
    
    # Wait for completion
    while true; do
        STATUS=$(curl -s "http://localhost:8000/api/v1/jobs/$JOB_ID" | jq -r '.status')
        if [ "$STATUS" = "completed" ]; then
            curl -s "http://localhost:8000/api/v1/jobs/$JOB_ID/result" -o "${file%.png}.md"
            break
        fi
        sleep 2
    done
done
```

**Example Monitoring Script:**
```python
import time
import psutil
import requests

def monitor_ocr_job(job_id):
    start_time = time.time()
    start_memory = psutil.virtual_memory().used
    
    # Poll job status
    while True:
        response = requests.get(f"http://localhost:8000/api/v1/jobs/{job_id}")
        job = response.json()
        
        if job['status'] == 'completed':
            end_time = time.time()
            end_memory = psutil.virtual_memory().used
            
            print(f"Processing time: {end_time - start_time:.2f}s")
            print(f"Memory usage: {(end_memory - start_memory) / 1024 / 1024:.2f}MB")
            break
        
        time.sleep(1)
```

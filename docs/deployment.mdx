# Documentation Deployment Guide

This guide covers how to deploy the Document Converter API documentation using Mintlify.

## Manual Deployment Options

<Tabs>
<Tab title="Vercel">

1. **Install Vercel CLI**:
   ```bash
   npm install -g vercel
   ```

2. **Deploy from docs directory**:
   ```bash
   cd docs
   vercel --prod
   ```

3. **Configure `vercel.json`**:
   ```json
   {
     "name": "doc-converter-docs",
     "version": 2,
     "builds": [
       {
         "src": "mint.json",
         "use": "@mintlify/cli",
         "config": {
           "installCommand": "npm install",
           "buildCommand": "mintlify build"
         }
       }
     ]
   }
   ```

</Tab>
<Tab title="Netlify">

1. **Create `netlify.toml`**:
   ```toml
   [build]
     command = "npm run build"
     publish = "_site"
   
   [build.environment]
     NODE_VERSION = "18"
   ```

2. **Deploy via Netlify CLI**:
   ```bash
   npm install -g netlify-cli
   netlify deploy --prod
   ```

</Tab>
<Tab title="GitHub Pages">

1. **Create workflow** `.github/workflows/docs.yml`:
   ```yaml
   name: Deploy Documentation
   
   on:
     push:
       branches: [ main ]
       paths: [ 'docs/**' ]
   
   jobs:
     deploy:
       runs-on: ubuntu-latest
       steps:
         - uses: actions/checkout@v3
         
         - name: Setup Node.js
           uses: actions/setup-node@v3
           with:
             node-version: '18'
             
         - name: Install dependencies
           run: |
             cd docs
             npm install
             
         - name: Build documentation
           run: |
             cd docs
             npm run build
             
         - name: Deploy to GitHub Pages
           uses: peaceiris/actions-gh-pages@v3
           with:
             github_token: ${{ secrets.GITHUB_TOKEN }}
             publish_dir: ./docs/_site
   ```

</Tab>
</Tabs>

## Custom Domain Setup

<Tabs>
<Tab title="Mintlify Cloud">

<Steps>
<Step title="Access Dashboard">
Go to your Mintlify dashboard
</Step>
<Step title="Navigate to Settings">
Navigate to **Settings** → **Custom Domain**
</Step>
<Step title="Add Domain">
Add your domain (e.g., `docs.yourdomain.com`)
</Step>
<Step title="Update DNS">
Update DNS records:
```
Type: CNAME
Name: docs
Value: your-site.mintlify.app
```
</Step>
</Steps>

</Tab>
<Tab title="Self-Hosted">

1. **Configure DNS**:
   ```
   Type: A
   Name: docs
   Value: your-server-ip
   ```

2. **Set up reverse proxy** (Nginx):
   ```nginx
   server {
       listen 80;
       server_name docs.yourdomain.com;
       
       location / {
           proxy_pass http://localhost:3000;
           proxy_set_header Host $host;
           proxy_set_header X-Real-IP $remote_addr;
       }
   }
   ```

</Tab>
</Tabs>

## Monitoring

### Health Check

Add a health check endpoint to monitor your documentation:

```javascript
// scripts/health-check.js
const https = require('https');

function checkHealth() {
  const options = {
    hostname: 'docs.yourdomain.com',
    port: 443,
    path: '/',
    method: 'GET'
  };

  const req = https.request(options, (res) => {
    console.log(`Status: ${res.statusCode}`);
    console.log(`Headers: ${JSON.stringify(res.headers)}`);
  });

  req.on('error', (e) => {
    console.error(`Health check failed: ${e.message}`);
  });

  req.end();
}

checkHealth();
```

## Performance Optimization

### 1. Build Optimization

```json
{
  "scripts": {
    "build": "mintlify build --optimize",
    "build:prod": "NODE_ENV=production mintlify build --optimize --minify"
  }
}
```

### 2. CDN Setup

Use a CDN for better performance:

```javascript
// mintlify.config.js
module.exports = {
  cdn: {
    enabled: true,
    domain: 'cdn.yourdomain.com'
  }
};
```

### 3. Caching Headers

Configure caching in your web server:

```nginx
location ~* \.(js|css|png|jpg|jpeg|gif|ico|svg)$ {
    expires 1y;
    add_header Cache-Control "public, immutable";
}

location ~* \.(html|json)$ {
    expires 1h;
    add_header Cache-Control "public, must-revalidate";
}
```

### Content Security Policy

Add CSP headers for security:

```nginx
add_header Content-Security-Policy "default-src 'self'; script-src 'self' 'unsafe-inline'; style-src 'self' 'unsafe-inline'; img-src 'self' data: https:; font-src 'self' data:";
```
